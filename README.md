# Student Management System (SMS)

## 📌 About

A small web application for managing student records using HTML, CSS, and JavaScript.

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
* Lambda/Arrow Functions
* LocalStorage

## ✨ Features

* Add student details
* Display student records
* Search students
* Automatic grade calculation
* Delete student records
* Responsive design

## 📂 Project Structure

```text
SMS/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🎯 Objective

To develop a simple and user-friendly Student Management System while demonstrating JavaScript Lambda/Arrow Functions.
